# 12V Socket Detector — план

## Мета

Пристрій на ESP32, який:

- контролює наявність 12V на вході **Main** (адаптер від розетки);
- автоматично (апаратно) перемикає навантаження на **павер** (резервне 12V джерело), коли Main зникає;
- керує одним виходом **12V / 1A** (на ньому висить Wi-Fi роутер → роутер живе під час відключень);
- шле на сервер (VPS) пульс «I'm alive», події зміни джерела живлення і рівень заряду павера;
- сервер сповіщає про: зникнення/повернення світла, низький заряд павера, зникнення пульсу.

## Архітектура

```
Main 12V ──[F]──[Шотткі D1]─────────────────┐
                │                           │
                └─(керує затвором Q1)       ├── ШИНА 12V ─┬─ MOSFET ─► OUT 12V 1A (роутер)
                        ▼                   │  + 2200µF   └─ DC-DC 12→5V ─► ESP32 DevKit
Павер 12V ─[F]──[P-MOSFET Q1]──[Шотткі D2]──┘
   │                                                        ▲
   └── дільник 100k/22k ─► GPIO35 (ADC1)       Main ── дільник 100k/22k ─► GPIO34 (ADC1)

ESP32 ──Wi-Fi──► роутер (живиться від OUT) ──► Інтернет ──► VPS
                                                             ├─ Mosquitto (MQTT, TLS)
                                                             ├─ сервіс: історія (SQLite), вочдог пульсу,
                                                             │          веб-сторінка, керування виходом
                                                             └─ ntfy → push на телефон
Raspberry Pi 4 (вдома) — опціонально: стенд для розробки / локальна панель.
```

### Ключові рішення

| Рішення | Чому |
|---|---|
| Перемикання Main → павер апаратне (P-MOSFET + Шотткі), не через ESP | мікросекунди замість десятків мс; не залежить від прошивки |
| Пріоритет Main (Q1 закритий, поки є Main) | павер не розряджається, поки є світло |
| Вимір напруг через ADC1 | ADC2 не працює разом з Wi-Fi |
| Роутер живиться від нашого OUT | інакше під час відключення немає зв'язку |
| Сервер на VPS, а не вдома | вочдог мусить бути поза зоною відключення |
| MQTT з LWT | брокер сам публікує `offline`, якщо ESP зникла |
| ntfy замість Telegram | self-hosted, open source, без акаунтів |
| Входи описані таблицею каналів | легко додати ще входи без зміни логіки |

## MQTT-протокол

Базовий топік: `psd/<device_id>/` (`device_id` за замовчуванням `psd-XXXXXX` з MAC).

| Топік | Напрям | Retained | Вміст |
|---|---|---|---|
| `status` | ESP → | так | `online` / `offline` (LWT) |
| `state` | ESP → | так | JSON: джерело, напруги входів, стан виходу |
| `event` | ESP → | ні | JSON: `boot`, `input`, `source`, `backup_low`, `output` |
| `heartbeat` | ESP → | ні | JSON: `seq`, `uptime_s`, `rssi`, `source` |
| `cmd/out` | → ESP | ні | `on` / `off` / `off:<сек>` / `toggle` (off завжди тимчасовий — failsafe) |
| `cmd/ping` | → ESP | ні | будь-що → негайний heartbeat + state |
| `cmd/reboot` | → ESP | ні | `yes` → перезавантаження |

## Події та сповіщення

| Подія | Хто визначає |
|---|---|
| Світло зникло, працюємо від павера | ESP (`source` → `backup`) |
| Світло повернулось + тривалість | ESP (`source` → `main`), тривалість рахує сервер |
| Павер сідає | ESP (`backup_low`) |
| Пристрій перезавантажився (збій) | ESP (`boot` з `reset_reason` ≠ POWERON) |
| Пульс зник | сервер (таймаут `heartbeat` / LWT `offline`) |

## Етапи

1. **Прошивка — крок за кроком** (пишемо самі; еталон — гілка `reference`):
   - [ ] 1.1 Порожній проєкт PlatformIO, Serial, LED — `setup()` / `loop()`
   - [ ] 1.2 АЦП: напруга з дільника, калібрування
   - [ ] 1.3 Фільтр, гістерезис, антидребезг → надійне «є / немає»
   - [ ] 1.4 Вихід: MOSFET, керування з Serial
   - [ ] 1.5 Неблокуючий код: `millis()` замість `delay()`
   - [ ] 1.6 Wi-Fi → MQTT → LWT і пульс
   - [ ] 1.7 Черга подій, watchdog, розбиття на модулі
2. **Залізо**: принципова схема з номіналами, макет на DevKit + готові модулі (DC-DC, MOSFET).
3. **Сервер (VPS)**: Docker Compose — Mosquitto (TLS + паролі), сервіс на Python (SQLite, вочдог, веб/API), ntfy.
4. **Інтеграція**: TLS на ESP, provisioning Wi-Fi через captive portal, OTA.
5. **Тести**: Main off/on, павер сів, Wi-Fi зник, рестарт брокера, брязкіт контакту.
6. **Корпус, монтаж.**

## Відкриті питання / ризики

- Павер може сам вимикати вихід 12V без навантаження → перевірити (година без навантаження, поміряти напругу).
- Точні номінали схеми пріоритету (Vgs Q1 при близьких напругах Main і павера).
- Калібрування АЦП під конкретні резистори.
